## 🏛️ Features

### 1. State 1: Liquid Glass Authentication
- Modern dark glassmorphism card with ambient cosmic mesh and gold accents.
- Interactive mouse-tracking particle constellation canvas.
- 3D perspective card tilt with dynamic hover reflection.
- Input validation with card shake feedback.
- One-click instant login button.

### 2. State 2: Main Heritage Portal
- **Contributors Showcase:** Featured project hero section introducing all 5 team members and registration numbers.
- **Activity 1 — Art History Timeline:** Chronological journey through 14 canonical Indian art masterpieces from 2500 BCE to 1760 CE.
  - Interactive era filtering (*Ancient*, *Mauryan*, *Classical*, *Medieval*, *Late Medieval*).
  - High-resolution modal viewer with detailed historical context, medium, epoch, and provenance.
  - Keyboard navigation (Left/Right arrow keys and Escape).
- **Activity 2 — Geographic Art Map:** Full-screen Leaflet.js interactive dark-canvas map.
  - 14 geographically anchored markers with zero-latency coordinate synchronization.
  - Location quick-filter pills for rapid navigation across historic sites.
  - Slide-out detail drawer with high-resolution imagery and architectural history.
  - Cross-activity jump links ("Locate on Map" / "Inspect in Timeline").
